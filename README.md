# GlowStore - E-commerce de Cosméticos e Beleza

## 1. Objetivo e Finalidade
Loja virtual moderna e minimalista voltada para produtos de beleza, maquiagem e cuidados pessoais.

## 2. Tecnologias Utilizadas
- React, TypeScript, Vite, Tailwind CSS, Lucide React, React Router

## 3. Arquitetura e Estrutura de Diretórios
Frontend SPA reativo estruturado em páginas de vitrine, categoria e carrinho de compras.

## 4. Principais Arquivos e Responsabilidades
- `src/App.tsx`: Catálogo e navegação de produtos.
- `vite.config.ts`: Configuração do bundler Vite.

## 5. Funcionalidades Identificadas
- Vitrine de produtos com filtros por categoria de beleza
- Carrinho de compras integrado
- Design responsivo de alta conversão

## 6. Como Compilar ou Executar
```bash
npm install
npm run dev
```

## 7. Estado Atual do Projeto
**Completo**

## 8. Pendências e Limitações Identificadas
Conexão com gateway de pagamento Mercado Pago ou Stripe.
